### Параметры командной строки

| Параметр | Короткая форма | Описание | Значение по умолчанию |
|----------|----------------|----------|-----------------------|
| `--help` | `-h` | Справка | - |
| `--dir` | `-d` | Директории для сканирования (можно несколько) | - |
| `--exclude` | `-e` | Директории для исключения (можно несколько) | - |
| `--depth` | `-p` | Уровень сканирования (0 = только указанная директория) | 0 |
| `--size` | `-s` | Минимальный размер файла в байтах | 1 |
| `--mask` | `-m` | Маска имени файла (regex, без учёта регистра) | `.*` |
| `--block` | `-b` | Размер блока для чтения в байтах | 4096 |
| `--hash` | `-a` | Алгоритм хэширования: `crc32` или `md5` | `crc32` |

### Формат вывода

Группы идентичных файлов выводятся на стандартный вывод. Каждый файл на отдельной строке, группы разделены пустой строкой:

```
/path/to/file1.txt
/path/to/file2.txt
/path/to/duplicate.txt

/path/to/image1.jpg
/path/to/image_copy.jpg
```
